# Демо-приложение к занятию MVI

На этом занятии мы познакомимся с архитектурой мобильных приложений MVI: Model-View-Intent.
Модули приложения:

- [mvvm](mvvm) - Традиционное приложение MVVM и Navigation Component.
- [uistate](uistate) - Приложение с рисованием полного состояния View
- [mvi](mvi) - Принципиальная структура MVI-приложения
- [statemachine](statemachine) - Вариант мультиплатформенного MVI приложения с использованием библиотеки [CommonStateMachine](https://github.com/motorro/CommonStateMachine)
